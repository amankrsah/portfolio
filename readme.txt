##  Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Styling & Layout:** CSS Grid, Flexbox, Custom Variables
* **Libraries/Plugins:** Swiper.js (Sliders), BasicLightbox (Modals), Anime.js (Animations)

##  Repository Structure
* `/css` - Contains `styles.css` (custom styling) and `vendor.css` (third-party library styles).
* `/js` - Contains `main.js` (custom scripts) and `plugins.js` (vendor scripts).
* `/images` - Contains profile photos, project thumbnails, and SVG icons.
* `index.html` - The main single-page portfolio layout.
* `Aman_ke_sah_resume.pdf` - Downloadable resume file.

##  Key Projects Showcased
* **SecureHostel:** Geofenced & Biometric Attendance System (React, FastAPI, DeepFace)
* **Intersectional Fairness:** Bias mitigation using Genetic Algorithms (Python, DEAP)
* **Kearth Solutions:** Corporate MERN Stack Web Platform
* **Task-Tracer, Devlok Transport, QR Generator, Tic-Tac-Toe:** Earlier foundational projects.

##  Setup & Deployment
This is a static website. No complex build tools are required.
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. To deploy, simply upload the files to GitHub Pages, Netlify, Vercel, or any static hosting service.
